# Meuble Amri

Site vitrine du showroom tunisien **Meuble Amri** — packs salon, chambre, salle à manger et décoration.

## Développement

```sh
npm install
npm run dev
```

Ouvre ensuite [http://localhost:8080](http://localhost:8080) (ou le port indiqué dans le terminal).

## Build

```sh
npm run build
npm run preview
```

## Contenu

Les visuels se trouvent dans `src/assets/` :

- `logo.jpg` — logo de la marque
- `hero.jpg` — visuel d'accueil
- `pack-*.jpg` — photos des packs produits
